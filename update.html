Update orenOS 1.0

Get the new boot menu, boot animation, wallpapers and future updates on a system you already installed. It takes about 5 minutes.

Before you start. You need an internet connection and orenOS 1.0 already installed. Updating changes the boot menu, so back up your important files first.

Step by step

  1. Open a terminal (in the applications menu, search for “Terminal”).
  2. Add the orenOS update source (you do this only once):
    wget https://orenos-official-website.netlify.app/apt/orenos-release.deb
sudo apt install ./orenos-release.deb
  3. Install the orenOS update (first time only, this also adds the update notifications):
    sudo apt update
sudo apt install orenos-branding
  4. Restart your computer. You should see the new boot menu and boot animation.

Later updates

After this, orenOS updates arrive like any other update. You will see a notification, or you can open orenOS Center → Update system. In a terminal:

sudo apt update
sudo apt full-upgrade

Check that it worked

apt policy orenos-branding | head -3

The line Installed: must show a version number, not “(none)”.

Verify the signing key

The official orenOS signing key has this fingerprint:

Compare it with the output of:
gpg --show-keys /usr/share/keyrings/orenos-archive-keyring.gpg


If something goes wrong


    

  • “NO_PUBKEY” or “not signed”: download orenos-release.deb again and check that your computer's date and time are correct.
    • 

  • “Unable to locate package orenos-branding”: run sudo apt update again and make sure step 2 finished without an error.
    • 

  • The boot menu looks unchanged: run sudo update-grub, then restart.
    • 

  • Only install from this site. Never run commands from a source you do not trust.
